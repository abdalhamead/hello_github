# مرحبًا جيتب

تطبيق Flutter تجريبي يهدف إلى تجربة إنشاء مشروع ورفعه على GitHub باستخدام Termux.

## المميزات

- مكتوب بلغة Dart باستخدام Flutter.
- يحتوي على ملف `pubspec.yaml` وملف `main.dart`.
- تم رفع المشروع من بيئة Termux.

## الهدف

تعلم أساسيات استخدام Git وGitHub في بيئة Android باستخدام Termux.

1. تأكد من تثبيت Flutter.
